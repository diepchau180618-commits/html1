# 🍔 Jollibee Showcase - Vị Ngon Giòn Rụm, Niềm Vui Lan Tỏa 🐝

Website quảng cáo tương tác cao cấp cho thương hiệu **Jollibee Vietnam** được xây dựng với **Tailwind CSS**, thiết kế **Responsive riêng biệt cho Mobile & PC**, âm thanh hiệu ứng sống động và Trợ lý ảo **JolliBot Companion**.

## ✨ Điểm Nổi Bật Kỹ Thuật
- **Công nghệ giao diện**: Tailwind CSS & Glassmorphism hiện đại.
- **Tối ưu thiết bị**: Thiết kế riêng biệt cho Mobile (thanh điều hướng đáy màn hình) và PC (Header Sticky Glassmorphism).
- **Mã nguồn sạch (Clean Code)**: JavaScript ES6+ module hóa hoàn toàn, giải thích cặn kẽ từng dòng lệnh.
- **Âm thanh Web Audio API**: Tự động phát âm thanh hiệu ứng mà không lo lỗi thiếu tệp âm thanh ngoài.

## 🚀 Khởi Chạy Nhanh (Quick Start)

### Cách 1 (Nhanh nhất):
👉 Nhấp đúp chuột vào file [`start_server.bat`](start_server.bat) để tự động mở web trên trình duyệt!

### Cách 2:
👉 Mở trực tiếp file [`index.html`](index.html) bằng bất kỳ trình duyệt nào (Chrome, Edge, Firefox).

### Cách 3 (Dùng Command Line):
```bash
# Cài đặt thư viện (lần đầu)
pip install -r requirements.txt

# Khởi chạy Backend & Web (khuyên dùng để dùng đầy đủ AI BeeBot)
python backend/app.py
```
Truy cập: `http://localhost:5000` (Backend API & Giao diện tích hợp)
